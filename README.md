# Mohid Choudhry — Personal Portfolio

A personal portfolio website with five pages: Home, About Me, Projects, Skills, and Contact. It is built with plain HTML, CSS, and JavaScript.

## Live site

[https://mohiid.github.io/Portfolio/](https://mohiid.github.io/Portfolio/)

## View locally

1. Clone this repository.
2. Double-click `index.html` to open the site in a browser, or open it with Live Preview in VS Code.

No build tools or installs are needed.

## Files

- `AGENTS.md` — project instructions
- `TESTING.md` — site test plan and results
- `style.css` — shared page styles
- `script.js` — site interactions
- `images/` — project images
