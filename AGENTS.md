# Portfolio Website

## Site
Personal portfolio for Mohid, a college student and soccer athlete. Pages: Home (`index.html`), About Me (`about.html`), Projects (`projects.html`), Skills (`skills.html`), and Contact (`contact.html`).

## Design
Use a simple, modern style with a smooth white gradient and a small yellow accent. Use Arial.

## Rules
- Use plain HTML, CSS, and JavaScript only. No frameworks, npm, or inline styles.
- Use one external CSS file and relative file paths.
- Use semantic HTML and one `<h1>` per page. Give every image alt text.
- Do not include a phone number or home address.
- Make text easy to read with good color contrast.

## Git
After each task, commit with a clear message, then push to GitHub.
- JavaScript lives in `script.js`.
